# CHU, CHEN-YU 曲宸宇

[一卦 yigua.art](https://yigua.art/) · [公開專案](https://github.com/poplolioi11?tab=repositories)

你好，我是曲宸宇。我以「一卦」為起點，探索傳統文化、數位人文、互動設計與 AI 協作，希望把文化材料與想法做成他人可以閱讀、使用和延伸的作品。

## 我在做的事

| 方向 | 內容與作品 |
| --- | --- |
| 文化與互動設計 | [一卦](https://yigua.art/)：以卦象與原典為核心的《易經》數位體驗；另以[一卦 Minecraft](https://github.com/poplolioi11/yigua-minecraft)探索遊戲中的文化互動。 |

古籍資料的初錄、校讀、疑字、授權與可用範圍，以各專案的說明及版本紀錄為準；AI 輔助初錄仍需依原圖覆核。在地化連結記錄的是問題回報，修正進度以各上游專案為準。

## 我怎麼做

- **先釐清問題與來源**：界定要解決的需求、材料範圍與使用情境，做出內容、美學和互動上的取捨。
- **透過 AI 協作推進**：由 AI 協助研究、資料整理、程式與原型實作；我著重需求定義、工作拆解、成果判斷與整合。
- **以證據持續修訂**：核對來源與實際行為，安排必要測試，記錄疑問、限制及尚待驗證的部分，再逐步公開可追溯的成果。
